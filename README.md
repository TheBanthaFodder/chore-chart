# chore-chart
Simple Chore Chart and tracker with a MySQL database, and a very simple web interface. More of a proof of concept. Work In Progress!

# Plans
MySQL database containing chores, locations, and the relationships between them.
- Locations can be assigned chores
- Chores have a set interval
- Assigned Chores have a due date

Web-App UI:
- Supporting creation/deletion of chores
- Supporting creation/deletion of locations
- Assignment/Removal of chores to locations
- Mark chores complete (this should just reset the timer)
- Basic CRUD operations on the database
